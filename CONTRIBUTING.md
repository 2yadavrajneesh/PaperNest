# Contributing to PaperNest

Thank you for your interest in improving PaperNest.

## Before contributing

1. Read the project README and setup guide.
2. Create a separate branch for your changes.
3. Keep changes focused and explain the problem they solve.
4. Update documentation when setup steps or behavior change.
5. Never commit secrets, real environment files, private documents, or generated temporary files.

## Pull requests

Please describe:
- What changed and why
- Any configuration or setup changes
- Known limitations or follow-up work

## Reporting issues

Include your operating system, relevant software versions, the command you ran, and the complete error message. Remove secrets and private file contents before sharing logs.
